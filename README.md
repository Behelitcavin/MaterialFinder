# 素材さがし (Sozai Sagashi) v1.0.0

CLIP STUDIO PAINT にダウンロード済みの素材を、**自然な言葉**で探せるツールです。

[配布 ZIP をダウンロード / 배포 ZIP 다운로드](dist/SozaiSagashi_v1.0.0.zip?raw=true)

[한국어 설명은 아래에 있습니다 ↓](#한국어)

---

## できること

- **言葉で検索**：「雨の夜の路地裏」「桜吹雪のブラシ」「足を組んで座るポーズ」のように、思いついた言葉で探せます。
- **言語を選ばない**：素材の登録者が日本語で名前を付けていても、韓国語・英語で検索できます（逆も可）。
- **絵柄で探せる**：素材名やタグだけでなく、サムネイルの絵そのものも見て探します。タグが少ない素材も見つかります。
- **お気に入り**：よく使う素材を登録して、すぐ呼び出せます。
- **安全**：CLIP STUDIO の素材データは**コピーを読むだけ**です。元のデータは一切変更しません。

> 💡 外部フォルダ（PC内の画像・素材フォルダ）も同じように検索する機能を追加することもできます（この配布版には含まれていません）。

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11 |
| 必要なソフト | CLIP STUDIO PAINT（素材をダウンロード済みのPC）、[Python](https://www.python.org/downloads/) 3.10〜3.13 |
| 推奨 | NVIDIA GPU（RTX 20 / GTX 16 シリーズ以降、VRAM 6GB以上）※ドライバは最新に |
| 空き容量 | 約 12GB（AIモデル 約7GB + PyTorch 等） |

GPUが無い場合や、GTX 10 シリーズ以前のGPUでは自動的にCPUで動きます。ただし初回の解析に**数時間**かかることがあり、メモリ（RAM）16GB以上を推奨します（2回目以降は新しい素材だけなので速いです）。

## インストール

1. このフォルダを好きな場所に置きます（日本語を含まないパス推奨。例：`C:\Tools\SozaiSagashi`）。
2. **`setup.bat`** をダブルクリックします。
   - Python の仮想環境・PyTorch・AIモデル（約7GB）を自動でダウンロードします。
   - 終わると、スタートメニューに「素材さがし」が追加されます。

> Python のインストール時は「Add python.exe to PATH」にチェックを入れてください。

## 起動

- スタートメニューの **「素材さがし」**、またはフォルダ内の **`run.bat`** から起動します。
- 起動には20秒ほどかかります（AIモデルの読み込み）。
- **初回だけ**、素材のサムネイル解析に数分かかります。2回目以降は新しい素材だけを解析します。

### タスクバーにピン留めするには

スタートメニューで「素材さがし」と検索 → 右クリック →「タスク バーにピン留めする」。
（起動中のタスクバーアイコンを右クリックしてピン留めしてもOKです）

## 使い方

1. 上の検索欄に探したい素材を入力して **Enter**。
2. 結果をクリックすると、下に素材名と**素材パレット内の場所**が表示されます。
3. **ダブルクリック**（または「名前をコピー」）で素材名をコピー →
   CLIP STUDIO の**素材パレットの検索欄に貼り付け**ると、その素材がすぐ出てきます。
4. 「☆ お気に入り」で登録すると、「★ お気に入り」タブにまとまります。

- 右上のプルダウンで **画像 / ブラシ・ツール / ポーズ / 3D / テンプレート・フキダシ** に絞り込めます。
- CLIP STUDIO で素材を新しくダウンロードしたら **「再読み込み」** を押してください。
- 右上の **日本語 / 한국어** で表示言語を切り替えられます。
- **素材の保存場所を変更している場合**：既定の場所（`AppData\Roaming\CELSYSUserData` または Ver.1.10.12 以前の `ドキュメント\CELSYS`）に見つからないと、フォルダ選択が開きます。**「フォルダ…」** ボタンからいつでも変更できます（`CLIPStudioCommon` フォルダを選んでください）。

## 注意

- 非公式ツールです。CELSYS（セルシス）とは関係ありません。
- 起動中は GPU メモリを約 4GB 使います（初回の解析中もほぼ同じです）。重い作業（AI学習など）中は閉じてください。
- 結果の並び順は AI の判断なので、完璧ではありません。言い方を変えると見つかることがあります。

## アンインストール

1. このフォルダを削除します。
2. スタートメニューの「素材さがし」を削除します
   （`%APPDATA%\Microsoft\Windows\Start Menu\Programs\素材さがし.lnk`）。
3. AIモデルも消す場合は `%USERPROFILE%\.cache\huggingface\hub` 内の
   `models--google--siglip2-so400m-patch16-256` と `models--BAAI--bge-m3` を削除します。

## 한국어

**소재 찾기 (素材さがし)** — 클립스튜디오에 다운로드한 소재를 **편한 말로** 찾는 도구입니다.

### 할 수 있는 것

- **말로 검색**: "비 오는 밤 골목", "벚꽃 흩날리는 브러시", "다리 꼬고 앉은 포즈"처럼 떠오르는 대로 입력하면 됩니다.
- **언어 상관없음**: 등록자가 일본어로 이름을 붙인 소재도 한국어·영어로 찾을 수 있습니다.
- **그림으로 찾기**: 이름·태그뿐 아니라 썸네일 그림 자체도 보고 찾습니다. 태그가 부실한 소재도 잡힙니다.
- **즐겨찾기**: 자주 쓰는 소재를 등록해 두고 바로 꺼낼 수 있습니다.
- **안전**: 클립스튜디오 소재 데이터는 **복사본만 읽습니다**. 원본은 전혀 건드리지 않습니다.

> 💡 외부 폴더(PC 안의 이미지·소재 폴더)도 같은 방식으로 검색하는 기능을 추가할 수 있습니다(이 배포판에는 포함되어 있지 않습니다).

### 동작 환경

- Windows 10 / 11, 클립스튜디오(소재 다운로드한 PC), [Python](https://www.python.org/downloads/) 3.10~3.13
- 권장: NVIDIA GPU(RTX 20 / GTX 16 시리즈 이상, VRAM 6GB 이상, 드라이버 최신)
- 여유 공간 약 12GB (AI 모델 약 7GB + PyTorch 등)
- GPU가 없거나 GTX 10 시리즈 이하면 자동으로 CPU로 동작합니다. 다만 첫 분석에 **몇 시간** 걸릴 수 있고, 메모리(RAM) 16GB 이상을 권장합니다(두 번째부터는 새 소재만 분석해서 빠릅니다).

### 설치 · 실행

1. 폴더를 원하는 곳에 둡니다(한글·일본어가 없는 경로 권장. 예: `C:\Tools\SozaiSagashi`).
2. **`setup.bat`** 더블클릭 → 가상환경·PyTorch·AI 모델(약 7GB)을 자동으로 받습니다. 끝나면 시작 메뉴에 "素材さがし"가 생깁니다.
3. 시작 메뉴의 **"素材さがし"** 또는 **`run.bat`** 으로 실행합니다. 오른쪽 위 **日本語 / 한국어** 에서 한국어로 바꿀 수 있습니다.
4. 실행에 20초 정도 걸립니다. **처음 한 번만** 썸네일 분석에 몇 분 걸리고, 이후에는 새 소재만 분석합니다.

> Python 설치 시 "Add python.exe to PATH"에 체크해 주세요.

**작업 표시줄 고정**: 시작 메뉴에서 "素材さがし" 검색 → 우클릭 → "작업 표시줄에 고정". (실행 중인 작업 표시줄 아이콘을 우클릭해서 고정해도 됩니다)

### 사용법

1. 검색창에 입력하고 **Enter**.
2. 결과를 클릭하면 아래에 소재 이름과 **소재 팔레트 안의 위치**가 나옵니다.
3. **더블클릭**(또는 "이름 복사")으로 이름을 복사해 클립스튜디오 **소재 팔레트 검색창에 붙여넣으면** 바로 나옵니다.
4. "☆ 즐겨찾기"로 등록하면 "★ 즐겨찾기" 탭에 모입니다.

- 오른쪽 위 드롭다운으로 이미지 / 브러시·도구 / 포즈 / 3D / 템플릿·말풍선만 볼 수 있습니다.
- 클립스튜디오에서 소재를 새로 받았으면 **"새로고침"** 을 눌러 주세요.
- **소재 저장 위치를 바꾼 경우**: 기본 위치(`AppData\Roaming\CELSYSUserData` 또는 Ver.1.10.12 이전의 `문서\CELSYS`)에 없으면 폴더 선택 창이 뜹니다. **"폴더…"** 버튼으로 언제든 바꿀 수 있습니다(`CLIPStudioCommon` 폴더를 선택).

### 주의

- 비공식 도구입니다. CELSYS와 관계없습니다.
- 실행 중에는 GPU 메모리를 약 4GB 사용합니다(첫 분석 중에도 거의 같습니다). 무거운 작업(AI 학습 등) 중에는 꺼 주세요.
- 결과 순서는 AI 판단이라 완벽하지 않습니다. 표현을 바꾸면 찾아지는 경우가 있습니다.

### 삭제

폴더 삭제 → 시작 메뉴의 "素材さがし" 삭제 → (모델도 지우려면) `%USERPROFILE%\.cache\huggingface\hub` 의 `models--google--siglip2-so400m-patch16-256`, `models--BAAI--bge-m3` 삭제.
